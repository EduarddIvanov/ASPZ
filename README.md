# ASPZ
## Перелік завдань

### zd1 - Дослідження роботи системного виклику write()

Програма демонструє, коли системний виклик `write()` може повернути кількість байтів, відмінну від запитаної для запису. Показано випадок з перериванням запису сигналом.

Компіляція та запуск:
```
gcc -o zd1 zd1.c
./zd1
```

### zd2 - Робота з системними викликами lseek() та read()

Програма демонструє переміщення покажчика файлу за допомогою `lseek()` та читання даних з файлу за допомогою `read()`. Файл містить послідовність байтів: 4, 5, 2, 2, 3, 3, 7, 9, 1, 5.

Компіляція та запуск:
```
gcc -o zd2 zd2.c
./zd2
```

### zd3 - Дослідження алгоритму швидкого сортування (qsort)

Програма досліджує ефективність стандартної функції `qsort()` на різних типах вхідних даних: відсортованих, зворотно відсортованих, випадкових, та інших. Також містить набір тестів для перевірки коректності роботи `qsort()`.

Компіляція та запуск:
```
gcc -o zd3 zd3.c
./zd3
```

### zd4 - Дослідження системного виклику fork()

Програма демонструє роботу системного виклику `fork()` для створення нового процесу та пояснює можливі результати виконання.

Компіляція та запуск:
```
gcc -o zd4 zd4.c
./zd4
```

### zdv6 - Дослідження впливу прапорця O_APPEND

Програма демонструє різницю між використанням прапорця O_APPEND та його відсутністю при записі даних у файл з декількох процесів одночасно. Експеримент ілюструє поняття стану гонки (race condition) та атомарні операції.

Компіляція та запуск:
```
gcc -o zdv6 zdv6.c
./zdv6
```

## Короткі висновки

1. `write()` може записати менше байтів, ніж запитано, наприклад, при перериванні сигналом.
2. Системний виклик `lseek()` дозволяє точно позиціонувати файловий покажчик перед читанням даних.
3. На ефективність `qsort()` значно впливає початкова структура масиву; найгіршими випадками є відсортовані у зворотному порядку масиви.
4. Після виклику `fork()` виконання програми продовжується у двох процесах, які працюють паралельно; батьківський процес отримує PID дочірнього, а дочірній процес отримує 0.
5. При одночасному записі з декількох процесів використання прапорця O_APPEND забезпечує атомарне додавання даних до файлу, запобігаючи стану гонки та втраті даних.
