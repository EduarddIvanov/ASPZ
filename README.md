# ASPZ

# Дослідження виділення пам'яті в мові C

## Опис проекту
Тести та дослідження виділення пам'яті на C

## Завдання

### 4.1 Максимальний обсяг пам'яті
- Дослідження максимального розміру пам'яті, який можна виділити за допомогою `malloc()`
- Аналіз обмежень типу `size_t`
- Перевірка поведінки на різних архітектурах (x86_64, x86)

### 4.2 Обробка від'ємних аргументів та переповнення
- Тестування поведінки `malloc()` при передачі від'ємних значень
- Аналіз наслідків переповнення цілих чисел
- Демонстрація безпечного виділення пам'яті

### 4.3 Виклик `malloc(0)`
- Вивчення поведінки `malloc()` при виклику з нульовим розміром
- Перевірка повернутого вказівника
- Дослідження можливості виклику `free()`

### 4.4 Помилки в циклі виділення пам'яті
- Ідентифікація типових помилок при виділенні пам'яті в циклі
- Демонстрація правильного підходу до виділення та звільнення пам'яті
- Важливість занулення вказівників після `free()`

### 4.5 Обробка помилок `realloc()`
- Тестування сценаріїв невдалого перевиділення пам'яті
- Вивчення поведінки оригінального вказівника при помилці

### 4.6 Особливі випадки `realloc()`
- Дослідження поведінки `realloc()` з `NULL` та нульовим розміром
- Еквівалентність `realloc(NULL, size)` та `malloc(size)`

### 4.7 Використання `reallocarray()`
- Демонстрація безпечного перевиділення масивів
- Запобігання переповненню при множенні розмірів

### Завдання 6: Стрес-тестування `malloc()`
- Тестування виділення великих обсягів пам'яті
- Аналіз часових характеристик виділення
- Перевірка системних обмежень пам'яті
