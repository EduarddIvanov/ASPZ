# File Access Permission Manager

Цей інструмент автоматично змінює права доступу до файлів залежно від кількості користувачів, які використовували файли.

## Опис

Програма читає лог-файл `usage.log`, де для кожного рядка вказано ім'я файлу та ID користувача, який його використовував.  
Після аналізу кількості унікальних користувачів для кожного файлу:

- Якщо кількість користувачів **≥ THRESHOLD** (за замовчуванням 3) — права доступу змінюються на `0644` (читання для всіх користувачів).
- Інакше права встановлюються на `0600` (доступ тільки для власника).

## Структура usage.log

Файл `usage.log` має бути у форматі: /home/user/file.txt

## Запуск
sudo ./permission_manager

## Обмеження
Програма не перевіряє наявність самих файлів перед зміною прав доступу.
Максимальна кількість унікальних користувачів для одного файлу обмежена константою MAX_USERS.
Максимальна кількість оброблюваних файлів обмежена розміром масиву.
