# ASPZ
# Огляд
Ця програма написана мовою C і дозволяє конвертувати введену користувачем кількість секунд у години, хвилини та секунди.

# Функціональність програми
Користувач вводить кількість секунд (може бути від'ємним або додатним числом).
Програма розраховує еквівалентний час у годинах, хвилинах та секундах.
Якщо введене число від'ємне, програма виводить результат у форматі "назад у часі".

# Приклад використання
Enter the number of seconds: 3661
3661 seconds is equivalent to 1 hours 1 minutes 1 seconds.

Enter the number of seconds: -3661
3661 seconds is equivalent to 1 hours 1 minutes 1 seconds ago.

# Обробка помилок
Якщо введено некоректне значення, програма знову запитує введення.
