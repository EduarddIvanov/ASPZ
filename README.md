# Memory Leak Demo in C

Цей проєкт демонструє приклад витоку пам'яті в мові програмування C. Програма постійно виділяє пам'ять у нескінченному циклі, не звільняючи її, але працює годинами без збоїв.

Програма працює без збою, оскільки:
У кожній ітерації циклу виділяється 1 байт пам'яті.
Пам'ять не звільняється, що викликає витік.
Затримка у 100 мс уповільнює витрати пам'яті, дозволяючи програмі працювати довго без аварійного завершення.
