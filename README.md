# ASPZ

## Функціональність
- Створення 5 дочірніх процесів за допомогою системного виклику `fork()`
- Кожен дочірній процес виводить свій номер
- Батьківський процес синхронно очікує завершення всіх дочірніх процесів
- Демонстрація базових принципів роботи з процесами в Unix

## Компіляція та запуск

### Компіляція
```bash
gcc -o zd6 zd6.c
```

### Запуск
```bash
./zd6
```

## Очікуваний вивід
```
Дочірній процес 1
Дочірній процес 2
Дочірній процес 3
Дочірній процес 4
Дочірній процес 5
```
## Використані системні виклики
- `fork()` - створення дочірнього процесу
- `wait()` - очікування завершення дочірнього процесу
- `exit()` - завершення процесу

## Висновок
Програма демонструє базові концепції багатопроцесорного програмування та управління процесами в Unix-подібних системах.
