# ASPZ
# Дослідження системних обмежень ресурсів

## Огляд проєкту
Цей проєкт демонструє роботу з системними обмеженнями ресурсів у Linux.

## Завдання

### 1. Дослідження Locked Memory (`locked_memory.c`)
- **Мета**: Вивчення обмежень зафіксованої пам'яті
- **Функціональність**:
  - Отримання поточних обмежень locked memory
  - Виведення м'яких та жорстких обмежень
  - Спроба зміни обмежень
- **Системні виклики**: `getrlimit()`, `setrlimit()`

### 2. Симуляція кидання кубика (`dice_roll.c`)
- **Мета**: Імітація кидання кубика з обмеженням розміру файлу
- **Функціональність**:
  - Генерація випадкових чисел від 1 до 6
  - Запис результатів у файл
  - Обмеження максимального розміру файлу
- **Системні виклики**: `setrlimit(RLIMIT_FSIZE)`

### 3. Симуляція лотереї (`lottery.c`)
- **Мета**: Генерація лотерейних чисел з обмеженням часу CPU
- **Функціональність**:
  - Генерація 7 унікальних чисел з діапазону 1-49
  - Генерація 6 унікальних чисел з діапазону 1-36
  - Обмеження часу виконання
- **Системні виклики**: `setrlimit(RLIMIT_CPU)`

### 4. Копіювання файлів (`file_copy.c`)
- **Мета**: Копіювання файлів з розширеними перевірками
- **Функціональність**:
  - Перевірка наявності аргументів
  - Перевірка прав читання/запису
  - Обмеження розміру вихідного файлу
- **Системні виклики**: `setrlimit(RLIMIT_FSIZE)`

### 5. Обмеження стеку (`stack_limit.c`)
- **Мета**: Демонстрація впливу обмежень стеку
- **Функціональність**:
  - Рекурсивна функція з великими локальними масивами
  - Встановлення обмеження розміру стеку
- **Системні виклики**: `setrlimit(RLIMIT_STACK)`

## Вимоги
- Операційна система: Linux
- Компілятор: GCC
- Бібліотеки: `<sys/resource.h>`

## Компіляція
```bash
gcc -o locked_memory locked_memory.c
gcc -o dice_roll dice_roll.c
gcc -o lottery lottery.c
gcc -o file_copy file_copy.c
gcc -o stack_limit stack_limit.c
```

## Запуск
```bash
# Приклади запуску
./locked_memory
./dice_roll
./lottery
./file_copy source.txt destination.txt
./stack_limit
```
