# ASPZ
# Завдання з системного адміністрування Linux

## Програми

### zd1 - Перевірка звичайних користувачів
Програма для перевірки наявності звичайних користувачів (UID > 1000) у системі, окрім вашого облікового запису. Використовує `getent passwd` для отримання інформації про облікові записи.

**Компіляція:**
```bash
gcc -o zd1 zd1.c
```

**Використання:**
```bash
./zd1
```

### zd2 - Виконання команд адміністратора
Програма, яка виконує `cat /etc/shadow` з правами адміністратора. Демонструє підвищення привілеїв через sudo.

**Компіляція:**
```bash
gcc -o zd2 zd2.c
```

**Використання:**
```bash
./zd2
```
Примітка: Програма запитає пароль sudo, якщо необхідно.

### zd3 - Тестування прав доступу до файлів
Створює файл як звичайний користувач, копіює його від імені root, а потім тестує модифікацію та видалення файлу. Демонструє, як власник файлу впливає на права доступу.

**Компіляція:**
```bash
gcc -o zd3 zd3.c
```

**Використання:**
```bash
./zd3
```

### zd4 - Ідентифікація користувача та групи
Виконує команди `whoami` та `id` для відображення поточного користувача та його груп.

**Компіляція:**
```bash
gcc -o zd4 zd4.c
```

**Використання:**
```bash
./zd4
```

### zd5 - Зміна власника файлу та прав доступу
Створює тимчасовий файл, змінює його власника на root та модифікує права доступу. Тестує різні комбінації прав доступу.

**Компіляція:**
```bash
gcc -o zd5 zd5.c
```

**Використання:**
```bash
./zd5
```

### zd6 - Перегляд прав доступу до директорій
Відображає власників та права доступу до файлів у домашній директорії, /usr/bin та /etc. Тестує можливість читання, запису та виконання різних файлів.

**Компіляція:**
```bash
gcc -o zd6 zd6.c
```

**Використання:**
```bash
./zd6
```

### zdv6 - Визначення системних користувачів за нестандартними критеріями
Визначає, які користувачі є "системними" на основі нестандартних критеріїв (не UID), таких як шаблони імен, тип оболонки та розташування домашньої директорії.

**Компіляція:**
```bash
gcc -o zdv6 zdv6.c
```

**Використання:**
```bash
./zdv6
```

## Примітки щодо безпеки

- Деякі з цих програм потребують прав адміністратора (sudo) для виконання.
