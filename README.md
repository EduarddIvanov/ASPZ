# ASPZ

### zd6.c - Зворотний відлік до події

Програма реалізує зворотний відлік з виведенням часу, що залишився до події. Використовує класичний підхід з функцією `alarm()` та обробкою сигналу `SIGALRM`.

**Особливості:**
- Приймає час у форматі години:хвилини:секунди через аргументи командного рядка
- Відображає зворотний відлік у реальному часі з оновленням кожну секунду
- Використовує безпечну функцію `write()` в обробнику сигналу
- Автоматично завершується при досягненні нульового часу

**Компіляція:**
```bash
gcc zd6.c -o countdown
```

**Використання:**
```bash
./countdown 0 5 30  # Відлік 5 хвилин 30 секунд
./countdown 1 0 0   # Відлік 1 година
```
## Приклад з лекції
У цьому прикладі було створено простий таймер із використанням сучасного POSIX-інтерфейсу: функцій timer_create, timer_settime та sigaction із сигналом SIGRTMIN. Таймер був налаштований на спрацювання щосекунди, після чого в обробнику сигналу виводилось повідомлення "Tick\n" у стандартний вивід. Для налаштування генерації сигналу використовувалась структура sigevent, а обробка сигналів здійснювалась асинхронно за допомогою sa_sigaction.

## Висновок

При роботі з обробниками сигналів важливо використовувати лише async-signal-safe функції. У прикладах використовується `write()` замість `printf()` саме з цієї причини.
