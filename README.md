# ASPZ
# C Memory Safety Test Cases

Цей приклад демонструє переповнення при читанні (buffer read overflow) у масиві фіксованого розміру мовою програмування C. Така помилка часто призводить до непередбаченої поведінки, збоїв або порушення безпеки.

Масив з 5 елементів читається у циклі до 10-го індексу, що спричиняє вихід за межі дозволеної пам’яті.
